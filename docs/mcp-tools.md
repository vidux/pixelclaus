# MCP tool reference

> Generated by `npm run docs` from the live server definition — do not edit by hand.

PixelClaus exposes **24 tools** (tool list ≈ 54 KB of JSON Schema), plus resources and prompts.
The server instructions sent to every client:

```text
PixelClaus: a pixel-art and sprite-animation editor you operate through tools.
Conventions: coordinates are whole numbers, 0-indexed with origin top-left; rects are {x,y,w,h}; line/path endpoints are inclusive; frames are 0-indexed; palette index 0 is ALWAYS transparent ("." in ASCII grids); durations are ms.
Loop: project_create → draw (batch many ops per call; each call = one undo step) → render (composite / indexed / value / silhouette / filmstrip) + analyze lint → fix → checkpoint → export.
Write sprites ≤48px with draw op "grid" (ASCII, one char per pixel); verify exact pixels with read_pixels before claiming positions. Previews include a 1x inset: judge readability at 1x, not at zoom.
Several agents may share this server: create your own project (a name already in use is refused with CONFLICT — pick another name unless the project is yours) and pass its id in every call.
Call guide (topics: overview, ascii, sprite, animation, tileset, palettes, lint, export, ops) when unsure.
```

## project_create

**Create project** · _mutates_

Create a sprite project. Defaults: indexed colour, palette "endesga-32", one layer "Layer 1", one 100ms frame. palette = preset name or list of hex colours (index 1..n; 0 is always transparent). background adds an opaque bottom "Background" layer. Returns the overview (layer ids, palette). Names are unique: if the name (or its id) is already used — maybe by another agent — this fails with CONFLICT unless ifExists:"suffix" (then the id gets a suffix such as hero-2; use the returned id in every call).

## draw

**Draw (batched ops)** · _mutates_

Apply a list of drawing ops to a layer/frame as ONE undoable, atomic step (any failing op rolls back the whole call; errors name the op index). Ops: pixels, grid (ASCII, see guide ascii), line, path, rect, ellipse, circle, polygon, fill, replace_color, gradient, pattern, outline, selout, shade, erase, clear, copy, paste, stamp, text, adjust, quantize (see guide ops). Coordinates are canvas pixels, 0-indexed, top-left origin; rect/ellipse/area use {x,y,w,h}; points are [x,y]; line endpoints are inclusive. Colours: palette index (0 = transparent), "#rrggbb[aa]", "transparent", a palette colour name, or "ramp:<name>:<step>". Every op may override layer, frame, ink (replace|behind|inside|blend) and clip (selection name). layer may be omitted only when the sprite has one non-background image layer. Set preview:true (or a view name) to get a PNG of the result in the same call.

| Parameter | Type | Req | Notes |
| --- | --- | --- | --- |
| `project` | string | ✓ | Project id or name |
| `layer` | string |  | Layer id (e.g. "L3") or unique name |
| `frame` | integer ≥0 |  | Default 0 |
| `ops` | op[] — see Draw ops below | ✓ |  |
| `symmetry` | {x?, y?} |  | Mirror drawing: x = vertical mirror axis (true = centre), y = horizontal axis |
| `ink` | "replace" \| "behind" \| "inside" \| "blend" |  | replace (default) \| behind: only empty pixels \| inside: only non-empty pixels (alpha lock) \| blend: alpha-composite (RGBA) |
| `clip` | string |  | Named selection restricting every op |
| `preview` | boolean \| "composite" \| "indexed" \| "value" \| "silhouette" |  |  |

## transform

**Transform** · _mutates_

Flip / rotate / scale / offset pixels. scope: cel (layer + frames), layer (all frames), sprite (everything; rotating a non-square sprite by 90° swaps width/height), selection (contents of a named selection on layer+frames, the mask moves too). op: flip_h | flip_v | rotate {angle, method?: rotsprite (default for non-90° angles, clean edges) | nearest, pivot?} | scale {factor | sx,sy, method?: nearest|scale2x|scale3x} (content scaled about the centre, canvas unchanged) | offset {dx, dy, wrap?} (wrap defaults to true for layer/sprite scope — seamless-tile checks — and false for cel/selection scope, which simply moves pixels).

| Parameter | Type | Req | Notes |
| --- | --- | --- | --- |
| `project` | string | ✓ | Project id or name |

## Errors

Every failure is a tool result with `isError: true` and text of the form

```text
Error [CODE]: what went wrong
Hint: what to do next (valid names, ranges, the exact call that fixes it)
```

Codes: `INVALID_ARGUMENT`, `NOT_FOUND`, `LOCKED`, `CONFLICT`, `UNSUPPORTED`, `LIMIT`, `INTERNAL`. Schema-validation failures use the same
shape. Mutations are atomic: an error in op 7 of a draw batch rolls back ops 0–6 as well.
